<task type="auto">
  <name>Task 1: Create idempotent video game category seed script</name>
  <files>scripts/seed-categories.ts</files>
  <action>
Create a Node.js/TypeScript seed script at `scripts/seed-categories.ts` that populates the Supabase database with 10-15 video game categories, each containing 100+ items with images.

**Category list** (at least 10, use discretion for the rest):
- Best RPGs of All Time
- Best FPS Games of All Time
- Best Action-Adventure Games
- Best Nintendo Games of All Time
- Best PlayStation Exclusives
- Best Open World Games
- Best Horror Games
- Best Fighting Games
- Best Racing Games
- Best Indie Games
- Best Strategy Games
- Best Sports Games

**Pipeline per category:**
1. Use Gemini (`@google/genai` with `gemini-2.0-flash`) to generate 120 game titles for the category. Prompt should ask for well-known, notable games with exact official titles. Use structured JSON output (responseMimeType: 'application/json').
2. For each title, use `IGDBFetcher.searchGames(title, 3)` to find the best match. Extract cover art URL from `cover.image_id` using IGDB image URL format: `https://images.igdb.com/igdb/image/upload/t_cover_big/${image_id}.jpg`.
3. If IGDB returns no cover, fall back to `fetchWikipediaImage(title)` from `@/lib/api/wiki-images`.
4. Validate image URLs with HEAD requests (timeout 5s). Replace dead links with null (placeholder-image component handles rendering).
5. Upsert items into Supabase `items` table with `onConflict: 'name,category'` and `ignoreDuplicates: true` for idempotency.
6. Create/upsert the `item_groups` row for each category.

**Rate limiting:**
- IGDB: max 4 concurrent requests (Twitch rate limits)
- Gemini: 1 request at a time per category (sequential categories)
- Wikipedia: max 6 concurrent requests
- HEAD image validation: max 10 concurrent

**Error handling:**
- If Gemini fails for a category, log error and skip to next category
- If IGDB fails for an item, fall back to Wikipedia, then null image
- Script should be resumable: since upserts skip duplicates, re-running picks up where it left off

**Execution:** The script should be runnable with `npx tsx scripts/seed-categories.ts`. Import Supabase client using direct env vars (not the Next.js server client which requires request context). Use `@supabase/supabase-js` directly with `NEXT_PUBLIC_SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.

Print progress: `[Category Name] Generating titles... -> Enriching 120 items... -> Saved 118/120 items (2 skipped)`
