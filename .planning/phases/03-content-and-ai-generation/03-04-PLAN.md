  <files>src/app/api/studio/generate/route.ts, .env.example</files>
  <action>
In src/app/api/studio/generate/route.ts, change both instances (lines ~301 and ~396) of:
```
const useEnrichmentPipeline = process.env.ENABLE_ENRICHMENT_PIPELINE === 'true';
```
to:
```
const useEnrichmentPipeline = process.env.ENABLE_ENRICHMENT_PIPELINE !== 'false';
```

This flips the default: enrichment pipeline (IGDB) is ON unless explicitly disabled. Operators who need to disable it (e.g., no IGDB credentials) can set ENABLE_ENRICHMENT_PIPELINE=false.

In .env.example, add under the appropriate section:
```
# Studio enrichment pipeline (IGDB for games, TMDB for movies, etc.)
# Set to 'false' to disable and use Wikipedia-only image lookup
ENABLE_ENRICHMENT_PIPELINE=true
```

<task type="auto">
  <name>Task 2: Add persist middleware and streamGenerate alias to studio-store</name>
  <files>src/stores/studio-store.ts</files>
  <action>
1. Add Zustand persist middleware to studio-store so draft state survives browser refresh:
   - Import `persist` from 'zustand/middleware'
   - Wrap the store creator with `persist(...)` using name 'goat-studio-store'
   - Configure `partials` to persist only draft-relevant state: generatedItems, listTitle, listDescription, category, topic, generateCount, criteriaMode, selectedPreset, customCriteria. Do NOT persist transient state like isGenerating, generationProgress, error, isPublishing.
   - Use the `partialize` option to select which state keys to persist:
     ```typescript
     partialize: (state) => ({
       generatedItems: state.generatedItems,
       listTitle: state.listTitle,
       listDescription: state.listDescription,
       category: state.category,
       topic: state.topic,
       generateCount: state.generateCount,
       criteriaMode: state.criteriaMode,
       selectedPreset: state.selectedPreset,
       customCriteria: state.customCriteria,
     })
     ```

2. Add a `streamGenerate` alias that calls `generateItems` to satisfy the artifact contract:
   - In the store actions, add: `streamGenerate: () => get().generateItems()`
   - Export it in the selector hooks so it is accessible
   - This is a naming alias only; generateItems remains the primary implementation

Note: The store currently uses `create` directly. Change to `create(persist(...))`. Follow the same pattern as other persisted stores in the codebase (e.g., grid-store, session-store) which use `persist` middleware with localStorage.
  </action>
