1. Create `src/hooks/use-auth-user.ts` — the unified auth hook:
   - Import useSupabaseAuth from `@/hooks/supabase-auth` and useTempUser from `@/hooks/use-temp-user`
   - Return: userId (Supabase user.id if authenticated, tempUserId if guest — always defined), user (Supabase User | null), session (Session | null), isAuthenticated (boolean), isGuest (boolean), isLoading (boolean), signInWithGoogle (calls signInWithOAuth('google')), signOut
   - On SIGNED_IN event via onAuthStateChange: call /api/auth/merge-guest with guest_id from localStorage and new user_id, then call upgradeToRegisteredUser(). Await the merge before proceeding.
   - IMPORTANT: useAuthUser() is Supabase-aware per user decision — no provider abstraction layer.
   - IMPORTANT: Ensure the supabase-auth hook uses the shared browser client from `src/lib/supabase/client.ts`, not a separate one. If supabase-auth/client.ts creates its own client, refactor it to use the shared singleton.

2. Rewrite `src/middleware.ts` — Supabase session refresh:
   - Use createServerClient from @supabase/ssr with cookie get/set handlers
   - Call supabase.auth.getUser() (NOT getSession) to refresh token
   - Matcher must exclude static assets: `/((?!_next/static|_next/image|favicon.ico|.*\\.(?:svg|png|jpg|jpeg|gif|webp)$).*)`
   - Do NOT protect any routes — guests have full access. Middleware only refreshes sessions.

3. Create `src/app/auth/callback/route.ts` — OAuth code exchange:
   - GET handler reads `code` and `next` params from URL
   - Uses createClient from `@/lib/supabase/server` to call exchangeCodeForSession(code)
   - On success: redirect to `next` param (default '/')
   - On error: redirect to `/?auth_error=true`

4. Create `src/app/api/auth/merge-guest/route.ts` — guest data merge:
   - POST handler, requires authenticated user (getUser() check)
   - Reads guest_id from request body
   - Updates all tables where user_id = guest_id to user.id (lists, list_items, and any others found)
   - Uses withErrorHandler wrapper per project convention
   - Returns { merged: true }

5. Update `src/types/database.ts` — add user_id_mapping type if database types are manually maintained there.
